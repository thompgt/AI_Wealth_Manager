# Pinned to exact versions.
#
# These were `>=` constraints, which means two installs a week apart could
# resolve to different dependency trees -- and this stack is unusually
# sensitive to that: yfinance renames `.info` fields and changed its
# auto_adjust default between minor releases, langchain's structured-output
# behaviour moved between majors, and pandas 3 changed semantics the
# analytics code relies on. A "works on my machine" bug in a system that
# sizes positions is not an acceptable class of failure.
#
# Upgrade deliberately: bump a pin, run `pytest`, commit.
